Import Penugasan dari Excel

📋 Langkah:
  1. Klik "Download Template" di bawah
  2. Buka file Excel → isi kolom: Email Guru, Kode Mapel, Nama Kelas
  3. Simpan file
  4. Klik "Pilih File Excel" → pilih file yang sudah diisi
  5. Klik "Mulai Import" → tunggu proses selesai
