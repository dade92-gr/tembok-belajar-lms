Tambah Guru

📋 Langkah membuat akun guru:
  1. Buka Supabase → Authentication → Users → Add user
  2. Isi email + password (min 6 karakter)
  3. Centang Auto Confirm User
  4. Klik Create user
  5. Salin UID dari daftar user, paste di bawah

Format: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

Harus sama dengan email yang Anda daftarkan di Supabase Auth
